# GitScout Dark Neon Glass 设计系统 v0.8.0

> 适用范围：React 正式应用与独立 HTML 原型。两端共享同一套视觉 token、组件语言和状态语义。

## 1. 设计方向

- **风格名称**：Dark Neon Glass / 暗色霓虹玻璃拟态。
- **产品气质**：技术情报工作台、数据可视化、可信赖的本地工具。
- **视觉关键词**：深海军蓝、青色数据高光、电光蓝、霓虹紫、半透明玻璃、细描边、柔和光晕。
- **原则**：数据优先、层级清楚、交互状态明确；霓虹用于强调，不以高饱和色覆盖大面积内容。

## 3. 组件规范

- **导航**：深色固定侧栏；当前项采用青蓝至紫色的低透明渐变，并保留图标高亮。
- **页面头部**：半透明顶栏 + 细描边；服务连接状态使用绿/红状态点。
- **卡片**：半透明深蓝底、1px 低对比边框、顶部微弱高光、16px 背景模糊；悬停只提升边框与阴影。
- **主视觉面板**：深蓝渐变 + 青紫局部光晕；标题和关键行动突出。
- **主按钮**：青色 → 蓝色 → 紫色渐变；次级按钮使用半透明深色面板。
- **表格**：表头略亮于卡片底色；行分隔线低对比；仓库链接用青色；数值使用等宽数字风格。
- **图表**：青蓝渐变线，紫色数据点，低对比网格线；图表区域不使用实心高饱和背景。
- **标签/状态**：成功=绿色，运行中=青色，警告=琥珀色，失败=玫红色；状态同时有文字，不只依赖颜色。
- **表单**：深色输入面板、清晰 focus ring、占位文字降低对比但保持可读。
- **弹窗**：深蓝实色玻璃面板 + 背景模糊；操作按钮保持明确层级。

## 4. 布局与尺寸

- 侧边导航：桌面宽度约 248px；窄屏按既有响应式规则收缩。
- 内容区：延续现有页面网格与间距，不改动信息架构。
- 卡片圆角：默认 12px；控件圆角 7–9px。
- 动效：150–220ms；遵循 `prefers-reduced-motion`。

## 5. React 与 HTML 同步约定

- React 主题入口：`frontend/src/theme.css`，在 `styles.css` 之后加载。
- HTML 原型保持单文件可打开；将本文件的颜色 token 和组件语义复制到其内嵌样式。
- 不在业务组件中硬编码新主题颜色；新增组件优先使用 `--gs-*` token。
- 所有页面继续使用现有 API 与 SQLite 数据，不用静态演示数据替换正式页面。
- 页面路由、表格字段、采集流程、推荐计算和研究数据行为保持不变。

## 6. 版本

- 版本：v0.8.0
- 主题：Dark Neon Glass
- 范围：全局外观同步，不涉及后端 schema 或业务 API 变更。
