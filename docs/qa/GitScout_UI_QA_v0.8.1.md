# GitScout UI 视觉与交互验收记录 v0.8.1

> 本次是 v0.8.0 Dark Neon Glass 基线上的 UI 质量修订，不改变后端 API、SQLite schema 或采集业务逻辑。

## 1. 验收范围

- React 正式应用：12 条路由，包含 11 个主导航页面和仓库详情页。
- HTML 独立原型：11 个主导航页面；新增可从项目列表、Trending / Stars 表格进入的仓库详情视图。
- 主题入口：frontend/src/theme.css 在 styles.css 后加载。
- 设计基线：Dark Neon Glass v0.8.0；工程修订版本：v0.8.1。

## 2. 源码级页面核对

| 核对项 | 结果 |
|---|---|
| React 路由映射 | 12 / 12，页面组件文件均存在 |
| 主导航 | 11 项 |
| 表单提交处理器 | 8 处 |
| 输入 / 选择 / 文本域变更处理器 | 58 处 |
| 点击处理器 | 68 处 |
| 活跃页面组件 TODO / FIXME | 未发现 |

以上数量来自 JSX 源码静态统计，不等同于浏览器端逐项人工点击结果。

## 3. v0.8.1 修复项

- 表格单元格中的仓库名称和重点数值统一为高对比文字，避免继承旧版深色文字。
- 采集任务统计卡片、任务详情状态条改为深色玻璃表面。
- Stars API 提示条改为暗色提示样式。
- 对比页快照选择器、采集计划输入框、推荐维度筛选器统一为深色输入控件。
- 推荐摘要数值、权重芯片和警告说明提高对比度。
- 感兴趣 / 研究工作区补齐搜索框、编辑输入框、笔记卡片和已选中项目行的暗色状态。
- 系统设置中的代码块、Token 配置说明统一深色样式。
- HTML 原型的旧变量 --ink、--muted、--line、--purple 改为映射到同一组 --gs-* Token。
- HTML 原型新增仓库详情视图，项目详情按钮不再只显示提示消息；关注状态可在原型中切换，并清理重复的演示辅助函数定义。

## 4. 自动化检查

- 新增 npm run check:theme：检查主题 Token、关键覆盖选择器、React 路由组件文件和 HTML 原型同步项。
- GitHub Actions 前端构建前执行设计系统一致性检查。
- 保留原有 TypeScript 构建、后端 SQLite 测试和 Windows 启动 / 备份 / 恢复烟雾测试。

## 5. 验收边界与待人工确认

本次完成源码级样式覆盖检查、原型交互补齐和 CI 自动化守护。当前 CI 没有配置 Playwright 像素差异或完整浏览器 E2E，因此以下事项仍需在用户本机启动正式服务后进行最终目视确认：

1. 1920×1080、1440×900、1366×768 三种桌面尺寸下的内容密度与滚动行为。
2. 900px 以下窄屏导航收缩、表格横向滚动和弹窗高度。
3. 用真实 SQLite 数据检查超长仓库名、空简介、超多 Topics 和异常状态。
4. 对趋势总览、Stars 总榜、智能推荐、周期对比、感兴趣项目、项目研究、采集记录、采集设置、系统设置和仓库详情逐页确认。

HTML 原型仍使用演示数据，不会调用 FastAPI 或修改 SQLite；正式 React 页面继续使用真实本地 API。
