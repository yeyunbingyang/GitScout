# GitScout
### 开源项目发现与研究平台

GitScout 是面向 GitHub 开源项目发现、趋势追踪、智能推荐与项目研究的平台。

> Discover · Track · Recommend · Research

- 产品版本：**v0.5.1**
- 品牌：**GitScout**
- 中文副标题：**开源项目发现与研究平台**
- 当前交付基线：品牌更名版需求说明书与配套 HTML 交互原型

## 当前产品范围

- GitHub Trending 日榜、周榜、月榜采集与历史查询
- 按 Stars 数量排序的总榜
- 项目比较与项目收藏
- 智能推荐与推荐评分
- 项目研究工作区与项目详情
- 采集日志及系统设置

具体功能边界、交互说明、数据字段与页面设计以 docs/requirements/ 中的当前版本需求说明书为准。
