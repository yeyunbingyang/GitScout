# GitScout Visual Assets

Local editable SVG assets, no remote icon CDN.

- brand-mark.svg — GitScout brand mark
- layers-mark.svg — page / project library marker
- repository-mark.svg — repository profile icon
- crown-gold.svg, crown-silver.svg, crown-bronze.svg — top-three ranking medals
- neon-waves.svg — subtle ambient wave decoration

Palette follows theme.css: cyan #48d5ef, blue #548dff, violet #9673ff.

- icon-preview.svg — visual index of the local brand, page, repository, ranking and ambient-effect assets.
